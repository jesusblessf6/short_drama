# 模型选型快照 — 2026-09

## 一、结论（推荐组合，待拍板）

**全栈收口到火山方舟单账号**（一个 key 通吃文本/图像/视频/语音，统一计费与审计）：

| 层 | 推荐模型 | 计费（快照价） | 单集预估（15-20 镜头） |
|---|---|---|---|
| 文本（创意层） | 方舟 GLM 系或 doubao-seed 文本模型 | 按 token（¥/百万级） | <¥1 |
| 图像（text2img） | **doubao-seedream-4-0** | **≈¥0.216/张**（官方 $0.03/张） | ≈¥4-5 |
| 视频（img2video） | **Seedance 2.0（或 2.0-fast）** | **≈¥1/秒**（fast 限时 **¥0.6/秒**） | ≈¥48-80（80s 成片） |
| 语音（audio） | 先 edge-tts（免费），升级豆包 TTS | 豆包 ≈¥1.3/千字（声音复刻 2.0） | ≈¥1-2 |

单集生成成本预估 **≈¥55-90**（不含重试）。M1 预算默认值（单集 ¥400）留有 ~4 倍重试余量，合理。

## 二、关键事实（与 2026-06 快照的差异）

1. **即梦 API 已开放且入口就是方舟**（2025-09-02 起，企业自助接入无需申请）：文生图 3.0/3.1、图生图 3.0、视频 3.0 Pro、OmniHuman 等。config.yaml 里遗留的 `jimeng` provider 命名应理解为"方舟上的即梦系模型"，**不再是独立账户体系**。
2. **图像**：Seedream 4.0（2025-09 发布）为当前主力，支持多图参考/图像编辑（**角色一致性的关键能力**），最高 4K；快照时已有 Seedream 5.0 Pro 的报道，接入前核实控制台最新版。
3. **视频**：Seedance 2.0 按 token 计费折合 ≈¥1/秒；2.0-fast 限时 ¥0.6/秒（2026-08 活动）；2026-08 已见 Seedance 2.5（第三方报价 $0.47-1.06/5s 起）。可灵 Kling 3.0 独立开放平台，≈$0.126-0.168/秒（0.9-1.2 units × $0.14/unit，$700/5000 units 资源包）。
4. **TTS**：豆包声音复刻 2.0 ≈¥1.3/千字；标准语音合成 ≈¥5-8/万字符。edge-tts 免费（非官方接口，商用合规风险自担——demo/开发期用，正式投产前拍板）。

## 三、首版接入方案（M2 技术样片）

- **文本**：沿用现有 LLMClient（OpenAI 兼容），生产需把 base_url 从 coding 端点换到方舟标准端点 + `ARK_API_KEY`；模型按控制台实价选 doubao-seed 或 GLM 系列（拍板项）。
- **图像**：方舟 Image Generation API（同步），model=`doubao-seedream-4-0`；逐镜头传角色参考图（多图参考输入）→ 对应 M2-3 角色一致性方案。
- **视频**：方舟视频生成 API（**异步任务**：提交→轮询→下载），正好落 M1 已建的 `external_task_id`/`submitted` 恢复契约；首版 seedance-2.0（fast 可选）。
- **TTS**：首版保持 edge-tts + 静音降级显式标记；豆包 TTS 作为 M2 后半升级项（`_jimeng_tts` 槽位改名/重写为方舟 TTS）。

## 接入确认（2026-09-29，官方《接入视觉模型》PDF 实测文档）

用户采购的是 **方舟 Agent Plan 企业版**，视觉模型接入已完成（`tests/test_ark_providers.py` 12 例）：

| 项 | 确认值 |
|---|---|
| 专属 Base URL | `https://ark.cn-beijing.volces.com/api/plan/v3`（**必须带 `/plan`**，/api/v3 和 coding 端点均不可用） |
| 专属 API Key | `AGENT_API_KEY` 环境变量（**Coding Plan 的 key 不可用**，须在方舟控制台 agentEnterprise 页签创建） |
| 图（已接线） | `POST /images/generations`，model `doubao-seedream-5-0-pro`（lite 即将下线勿用），size `1080x1920`（≤1.5K 档 ≈**100 AFP/张**），同步返回 url/b64 |
| 视频（已接线） | `POST /contents/generations/tasks`（content=[文本+首帧图 base64]）→ `GET /tasks/{id}` 轮询 → 下载 video_url；model `doubao-seedance-2.0`（4-15s；2.5 档位允许时 4-30s），ratio `9:16`，generate_audio=false（配音走本项目 TTS） |
| AFP 计费 | seedream-pro：≤1.5K 100/张、>1.5K 200/张；seedance-2.0：输入不含视频 480p/720p 系数 153、1080p 170 |
| 工程映射 | 异步任务正好落 M1 恢复契约：提交→`external_task_id` 回写状态；中断/超时→下轮凭 ID 续轮询**不重复扣费**；401/403→auth 终态不空烧重试 |

**预算换算参考**：一集 15-20 镜头 ≈ 图 1500-2000 AFP + 视频（5s×20×系数153≈单位待核）——按套餐 AFP 总额核对单集上限；config 里 cost_per_call 为 ¥ 折算估算（预算闸门用），实扣为 AFP。
